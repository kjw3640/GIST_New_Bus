# GIST NEW BUS

2026년 광주 시내버스 노선 개편을 GIST 구성원이 쉽게 살펴볼 수 있도록 만든 버스 안내 웹사이트입니다.

## 주요 기능

- GIST 인근 정류장과 경유 노선 지도, 노선별 필터 및 상세 경유지
- 주요 거점까지 갈아타지 않고 가는 노선과 예상 소요 시간
- 급행 03·05와 간선 03·05의 배차 간격 및 정차 정류장 비교
- 정류장별 진행 방향과 정차 노선 안내, 모바일 화면 지원

## 구성 및 실행

HTML, CSS, JavaScript로 작성된 정적 사이트입니다. `index.html`을 브라우저에서 열거나 정적 웹 호스팅에 이 폴더를 배포하면 됩니다. 지도는 MapLibre GL JS와 OpenFreeMap을 사용하며 인터넷 연결이 필요합니다.

## 데이터 안내

노선·예상 시간은 안내 자료를 바탕으로 작성된 정적 정보이며 실시간 도착 정보가 아닙니다. 이동 시간과 배차 간격은 실제 운행 상황에 따라 달라질 수 있습니다. 정류장 및 노선 정보는 광주시 개편 노선 검색 자료를 참고했으며, 운행 정보의 원자료 기준일은 2026년 10월 13일, 지도 정보 확인일은 2026년 10월 26일입니다. 출발 전 공식 안내를 확인해 주세요.

공식 노선 검색: http://125.136.150.185:8604/renewal/line

현재 공식 API 실시간 연동은 활성화되어 있지 않습니다. `api-adapter.js`와 `config.js`는 향후 연동을 위한 설정입니다.
